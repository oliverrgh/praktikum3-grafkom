Arsitektur Pemrosesan Input

Event-Based Listener

Sistem merespon sekali pada satu pemicu, misalnya tekan R untuk reset, T untuk ganti transform order, atau klik canvas untuk memindahkan Object A. Aksi sekali-tekan ini mengabaikan event.repeat supaya tidak terpicu berulang saat tombol ditahan.

State-Based Polling

Event keydown dan keyup hanya mengubah nilai boolean di tabel keys. Translasi, rotasi, dan scale dihitung di update(dt) setiap frame dikali deltaTime, menghasilkan gerakan kontinu yang konsisten di berbagai FPS.

Sistem ini memisahkan data transform (posisi, rotasi, scale) dari proses render. Setiap frame, JavaScript menyusun Model Matrix mat3 lewat komposisi T × R × S atau T × R, mengirimnya sebagai uniform ke vertex shader, lalu geometry segitiga yang sama digambar ulang untuk Object A, B, C, dan child. Challenge A–F (reset, preset, toggle order, mouse translation, parent-child, orbit) dibangun di atas pipeline yang sama.
